# 2026-10-27 更新紀錄

## 模組中介站

- 新增 `ApiGateway`，透過 `register` 註冊模組，再依 `call({ module, params, method? })` 分派呼叫。
- 新增轉帳 `TransferModule`（POST）、查詢用戶 `UserModule`（GET）與查閱區塊 `BlockModule`（GET）。
- Nuxt plugin 初始化時建立中介站及模組實例；同一個 app 重用實例，SSR 請求之間各自獨立。
- GET 參數放入 query，POST 參數放入 body；省略 method 時由模組決定，傳入不符的方法會在發送前拒絕。
- 加入未知模組、重複註冊與 HTTP 方法檢查，HTTP 錯誤往上傳遞，停用傳輸層自動重試。
- 新增 `useApiGateway` composable 與共用區塊鏈型別。
- 新增公開設定 `apiBase`，預設 `/api/demo`，可透過 `NUXT_PUBLIC_API_BASE` 指向其他後端。

## 可操作範例

- 新增 `/gatewayDemo` 頁面，提供模擬轉帳、用戶查詢及區塊查詢操作。
- 新增 `/api/demo/transfers`、`/api/demo/users`、`/api/demo/blocks` 三支示範 API。
- 檢查地址格式、正數金額及非負安全整數區塊編號。
- 示範 API 僅回傳模擬資料，不會簽署或廣播交易，也不會修改真實餘額。

- 共用 Vue 元件與類別檔採 PascalCase；頁面、CSS、函式、plugin 與測試檔採 camelCase。

- 統一 `initLoadingPage.vue`、`syncErrorPage.vue`、`initLoadingPage.css` 的大小寫。
- 修正 `blockAcoountMain.css` 拼字為 `blockAccountMain.css`。

- 移除未使用的 `app/method/methodApi.tsx`、`app/method/blockchainService.ts` 及空的 `app/method` 資料夾。
- 清除 `wallet.ts` 中已註解的舊服務引用與轉帳範例。
